# Сайт BreezeCAD

Статический сайт BreezeCAD — без сборки, без фреймворков и без сторонних запросов.
Публикуется через GitHub Pages из ветки `main` (корень репозитория).

| Файл | Что это |
| --- | --- |
| `index.html` | главная страница |
| `privacy.html` | политика конфиденциальности |
| `404.html` | страница «не найдено» |
| `assets/part.js` | 3D-модель штуцера на первом экране (чистый WebGL) |
| `assets/fonts/` | IBM Plex (OFL), урезанные до латиницы и кириллицы |
| `assets/img/` | скриншоты программы и фото авторов |

Кнопки «Скачать» ведут на `releases/latest/download/<файл>` репозитория
[MikeVerx/breezecad](https://github.com/MikeVerx/breezecad) — при каждом новом выпуске
сайт сам отдаёт свежую версию, править ничего не нужно.
